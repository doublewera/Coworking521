Как отобразить данные из базы на странице сайта?

  1. Подготовить путь в браузере, по которому мы будем отображать данные

    2. Необходимо отредактировать файлы urls.py в глобальном каталоге настроек проекта и в приложении, которое будет решать нашу задачу - в нашем случае mainpage/urls.py

    # Локальный диспетчер путей приложения mainpage
from django.urls import path

from . import views
urlpatterns = [
    # Путь в браузере: пустой, потому что главная страница
    # Функция: index, потому что именно её мы научили рендерить нужный для главной страницы шаблон
    path('',       views.index),
    path('tasks/', views.show_tasks),    # 127.0.0.1:8000/tasks/ - вызов функции show_tasks
]

  2. Написать функцию, которая будет вызываться по этому пути

    3. Теперь нужно написать функцию show_tasks в файле mainpage/views.py, которая будет превращать шаблон страницы в страниу (рендерить шаблон)

    def show_tasks(request):
    return render(  # создание страница сайта по шаблону
        request,
        'mainpage/task.html',
    )

  3. Сформировать HTML-шаблон

    4. Этот шаблон для начала может содержать только заголовок <h1>Здесь будут задачи</h1>

  4. Получить данные из базы

    5. Данные могут быть получены средствами Django внутри файла mainpage/views.py в новой функции. Для этого нужно импортировать модели и попросить класс моделей отдать нам все свои объекты.

            
# ВЫЗОВ ЭТОЙ ФУНКЦИИ ПРОИСХОДИТ В МОМЕНТ ОБРАЩЕНИЯ ПО ПУТИ В БРАУЗЕРЕ!
def show_tasks(request):
    my_tasks = models.Task.objects.all()  # Класс, дай нам все свои объекты, хранящиеся в БД
    # это аналог select *
    # Просмотрим циклом все полученные задачи
    for t in my_tasks:
        # t - один объект класса Task! можно вывести на печать его поле!
        print(t.deadline, t.description)
    return render(  # создание страница сайта по шаблону
        request,
        'mainpage/task.html',
    )
